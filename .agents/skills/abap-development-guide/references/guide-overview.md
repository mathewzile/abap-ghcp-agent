# ABAP Guide Overview

The DSAG ABAP Guide provides selected practical recommendations, not exhaustive or universally applicable rules (pp. 17-20).

## Chapter map

Use the topic-specific reference instead of loading the complete guide.

- Clean Core, pp. 32-52: clean-core definition, extension approaches, SAP-code modifications, architecture, and ABAP Cloud.
- Core Data Services, pp. 53-67: VDM, view types, annotations, view entities, access control, associations, extensibility, and analytics.
- Modern ABAP Development, pp. 68-107: architecture, packages, dependencies, object orientation, SOLID, design patterns, testability, Clean ABAP, modern language tools, and RAP.
- Software Testing with ABAP Unit, pp. 108-142: test strategy, fundamentals, test techniques, advanced techniques, tools, responsibilities, and Code-Test-Repeat.
- User Interface and Documentation, pp. 143-156: Fiori, SAPUI5, ABAP Doc, source documentation, and version-control documentation.
- Application Lifecycle Management, pp. 174-196: quality assurance, code review, quality gates, monitoring, version control, Git, deployment, security aspects, and risks.
- Open Source, pp. 197-219: abapGit, external dependencies, namespaces, and lifecycle.
- Integration, pp. 220-225: IDoc, RFC, SOAP, OData, HTTP, events, Clean Core, and borderline technology decisions.
- Security, pp. 226-261: vulnerabilities, secure development, authorization, secure file access, security reviews, automated checks, and ATC.
- Generative AI, pp. 262-271: developer responsibility, decision-making, SAP AI tools, GitHub Copilot, and AI-assisted development.
- Conclusion, p. 272.

## Application

For an implementation task, identify the affected chapter first. Combine the relevant guide reference with `clean-abap` for detailed style rules and with the target SAP framework rules for CDS, RAP, UI, or integration objects.
