# AI and Open Source

## Source scope

Based on Open Source, pp. 197-219, and Generative Artificial Intelligence, pp. 262-271.

## Open source

- Use approved channels such as abapGit and assess an external dependency's license, maintenance, security, compatibility, namespace, and lifecycle before adoption.

## Generative AI

- Review, test, secure, and validate generated ABAP as if it had been written manually.
- Verify APIs, release compatibility, authorization behavior, performance, error handling, and licensing before accepting AI-generated code.
